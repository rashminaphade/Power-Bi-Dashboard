# 📌Project Overview
This project focuses on analyzing employee attrition using Power BI.
The dashboard provides actionable insights into workforce trends, helping HR teams understand why employees leave and where retention strategies are needed.

# 🎯 Objectives
*Analyze overall employee attrition and key HR metrics.
*Identify high-risk attrition segments by age, salary, education, and job role.
*Support data-driven HR decision-making through interactive visuals.

# 🛠 Tools & Technologies
*Power BI
*DAX (Data Analysis Expressions)
*Data Cleaning & Modeling
*Interactive Visualizations

# 🚀 Key Features
*KPI cards for Total Employees, Attrition Rate, Avg Age, Avg Salary, Avg Tenure
Attrition analysis by:
*Gender
*Age Group
*Education Field
*Salary Slab
*Job Role
*Years at Company
*User-friendly and interactive dashboard layout
*Accurate calculations using custom DAX measures

# 🔍 Key Insights
*Highest attrition observed in the 26–35 age group.
*Employees in lower salary slabs (up to 5K) show maximum attrition.
*Laboratory Technicians and Sales Executives face higher turnover.
*Attrition is highest within the first 0–3 years of employment.
*Education background like Life Sciences and Medical shows higher attrition trends.

# ⭐ Why This Project Stands Out
*Solves a real-world HR problem.
*Focuses on business insights, not just visuals.
*Demonstrates end-to-end Power BI skills.
